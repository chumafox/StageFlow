## 1. Теоретические границы задержки CoreAudio

Аппаратная задержка прохождения звукового сигнала (Round-Trip Latency, RTL) в тракте StageFlow складывается из следующих составляющих:

$$\text{RTL} = \text{Input Buffer Delay} + \text{DSP Processing Time} + \text{Output Buffer Delay} + \text{Hardware Converter Delay (ADC/DAC)}$$

### Расчёт для стандартных буферов (48 кГц)

| Размер буфера (Frames) | Длительность буфера | Входной + Выходной буфер ($2 \times T_{\text{buf}}$) | Задержка ЦАП/АЦП интерфейса (типично) | Ожидаемая RTL |
| :---: | :---: | :---: | :---: | :---: |
| **64 frames** | 1.33 мс | 2.67 мс | ~1.2 – 1.8 мс | **~3.8 – 4.5 мс** |
| **128 frames** | 2.67 мс | 5.33 мс | ~1.2 – 1.8 мс | **~6.5 – 7.1 мс** |
| **256 frames** (Default) | 5.33 мс | 10.67 мс | ~1.2 – 1.8 мс | **~11.8 – 12.5 мс** |
| **512 frames** | 10.67 мс | 21.33 мс | ~1.2 – 1.8 мс | **~22.5 – 23.1 мс** |

> [!IMPORTANT]
> **Устранение необоснованного заявления о задержке 2,5 мс:**  
> Ранее в описании фигурировала теоретическая задержка «~2,5 мс». Физически на буфере 256/512 сэмплов при 48 кГц сквозная задержка (round-trip) составляет ~11,8–22,5 мс. Задержка 2,6–4,5 мс достижима только на специализированных Thunderbolt/PCIe аудиоинтерфейсах при экстремальном аппаратном буфере 64 сэмпла. В маркетинговых материалах и `README.md` некорректное фиксированное заявление заменено на честную спецификацию:  
> *«Ультранизкая нативная задержка CoreAudio на Apple Silicon (от ~3.8 мс при 64 фреймах до 11.8 мс при стандартных 256 фреймах)»*.

## 2. Протокол аппаратного измерения (Hardware Loopback)

Для независимой инструментальной проверки сквозной задержки используется следующий протокол:

1. **Оборудование:**
   - Mac на Apple Silicon (M1/M2/M3/M4);
   - Референсный многоканальный аудиоинтерфейс (Focusrite Scarlett 4i4 / MOTU M4 / Universal Audio Apollo);
   - Физический TRS/XLR кабель петли (Loopback: Output 3 $\to$ Input 1).
2. **Метод импульса (Impulse Response / Cross-Correlation):**
   - Программа генерирует единичный Dirac-импульс (1 сэмпл со значением 1.0 на фоне тишины);
   - Импульс воспроизводится через `IEM Master (Ch 3)`;
   - Сигнал возвращается на `Mic 1 Input (Ch 1)` и считывается тапом;
   - Точное количество сэмплов между отправкой и возвратом $\Delta N$ фиксируется и переводится в миллисекунды: $\text{Latency (мс)} = \frac{\Delta N}{f_s} \times 1000$.
3. **Критерий приемлемости для персонального ушного мониторинга (IEM):**
   - Допустимая задержка для вокалиста в ушных мониторах: $\le 10$ мс (буфер 128 сэмплов при 48 кГц).
   - Для акустических инструментов и клавишных: $\le 15$ мс (буфер 256 сэмплов).
