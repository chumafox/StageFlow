## 1. Обзор выполненных работ

В рамках этапа E11 дорожной карты [`IMPLEMENTATION_PLAN.md`](file:///Users/alexnovak/проекты/StageFlow/IMPLEMENTATION_PLAN.md) были реализованы сервисы неблокирующего импорта треков, версионированного персистентного хранения сетлиста и безопасной обработки перемещённых/отсутствующих файлов (**SF-11**):

1. **Сервис импорта треков (`TrackImporter.swift`, E11.1 / E11.2):**
   - Выделен отдельный компонент `TrackImporter`, изолированный от UI-потока.
   - **Устранена критическая ошибка SF-11:** полностью ликвидирована жёстко закодированная длительность в 180 секунд (`03:00`). Реальная длительность аудиофайлов вычисляется через `AVURLAsset(url:).load(.duration)` и `AVAudioFile`.
   - Встроено автоматическое извлечение метаданных (название трека, исполнитель) через `asset.load(.metadata)` и текстов/аккордов через `LyricsParser.extractLyricsAsync(from:)`.
   - Неподдерживаемые форматы строго отклоняются типизированной ошибкой `StageFlowError.unsupportedFileType`.
2. **Отзывчивый пакетный импорт (E11.3):**
   - Реализован метод `importBatch(urls:maxConcurrency:progressHandler:)` с ограниченным пулом задач (`withTaskGroup`, по умолчанию 4 параллельных потока).
   - Сбор ошибок изолирован: сбой или повреждение одного файла в пакете не прерывает загрузку остальных треков.
   - Прогресс пакетной обработки транслируется в UI через `ProgressView` в заголовке вкладки `Setlist`.
3. **Единый источник истины и обновление по ID (E11.4):**
   - Все операции выбора, удаления и повторного связывания треков производятся по уникальному идентификатору `UUID`.
   - При удалении выбранного трека `selectedTrackID` автоматически и безопасно переключается на соседний трек без рассинхронизации.
4. **Атомарное персистентное хранилище (`SetlistStore.swift`, E11.5 / E11.6):**
   - Создана структура данных `SetlistData` с версией схемы `schemaVersion = 1`.
   - Запись на диск выполняется строго атомарно через создание временного файла `setlist.tmp.<UUID>` с последующей атомарной заменой через `replaceItemAt`.
   - Сохраняются: порядок треков, `selectedTrackID`, размер шрифта суфлёра (`prompterFontSize`), статус автоскролла (`autoScrollEnabled`) и пользовательские MIDI-маппинги (`MIDIMappingStore`).
5. **Защита от повреждения данных (E11.6 / E11.10):**
   - При обнаружении синтаксических ошибок в файле хранилища (повреждённый JSON) сервис автоматически создаёт аварийную резервную копию `setlist.corrupt.<timestamp>.bak` в каталоге `Application Support` и инициирует безопасный запуск с дефолтными настройками, предотвращая краш приложения.
6. **Обработка отсутствующих/перемещённых файлов и Security-Scoped Bookmarks (E11.7 / E11.8):**
   - При загрузке сохранённого сетлиста проверяется физическое наличие файлов на диске.
   - Если файл был перемещён или удалён, запись трека **не удаляется** молчаливо из списка. Трек помечается статусом `isAvailable = false`, в UI отображается предупреждающий значок ⚠️ и кнопка «Relink».
   - Для каждого импортированного файла сохраняется `bookmarkData` (`.withSecurityScope`), что обеспечивает бесшовный доступ к файлам в песочнице macOS после перезапуска.
   - Метод `appState.relinkTrack(id:newURL:)` позволяет указать новый путь к файлу, восстанавливая доступность и актуализируя тайминги и тексты.
