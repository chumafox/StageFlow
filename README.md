# StageFlow 🎛️
### Нативный гибрид Stage Traxx 3 и Apple MainStage для macOS (Apple Silicon M1+)

**StageFlow** — профессиональное сценическое рабочее место для живых выступлений музыкантов и групп на macOS. Приложение объединяет плеер фонограмм и сетлистов с текстами/аккордами (функционал **Stage Traxx 3**) и живой CoreAudio DSP-микшер с независимой маршрутизацией FOH/In-Ear и обработкой микрофонов (функционал **Apple MainStage**).

---

## 🌟 Ключевые возможности

### 1. Сценический плеер и телесуфлёр (Stage Prompter):
- **Сетлисты и плейлисты:** порядок треков, мгновенное переключение, сохранение состояния между запусками.
- **Поддержка форматов:** WAV, AIFF, MP3, M4A, FLAC, AAC, CAF с честным вычислением реальной длительности.
- **Интеллектуальный импорт:** неблокирующая асинхронная загрузка файлов с отслеживанием прогресса и сохранением доступа через Security-Scoped Bookmarks.
- **Интеграция текстов и аккордов:** чтение встроенных ID3/MP4 метаданных (`lyrics`, `USLT`), внешних `.lrc` (с долями секунд до 3 знаков) и файлов ChordPro.
- **Prompter с вертикальным выравниванием:** аккорды отображаются строго над соответствующими слогами текста при любых размерах шрифта (18–48 pt).
- **Плавный автоскролл:** автоматическая прокрутка синхронизирована с аудиочасами CoreAudio без избыточных тиков анимации.

### 2. Двухшинный живой микшер FOH / In-Ear:
- **FOH Bus (Main Speakers):** общий мастер-микс в зал (CoreAudio каналы 1–2).
- **IEM Aux Bus (In-Ear Monitor):** независимый персональный ушной мониторинг для музыкантов (CoreAudio каналы 3–4).
- **Стерео-фоллбэк:** при работе со встроенным выходом Mac или 2-канальной картой IEM объявляется недоступным, исключая скрытое смешивание мониторного микса в порталы.
- **Независимые фейдеры и посылы:** каждый канал (Backing track, Mic 1, Mic 2) имеет раздельные регуляторы для зала и ушей.
- **Честный Mute и Solo:** Mute имеет наивысший приоритет над Solo, не сбивая настроенный уровень громкости.
- **14-сегментные светодиодные VU-индикаторы:** калиброванные показания в dBFS, раздельные Peak и RMS, удержание клиппирования Clip Hold (1.5 с) и логарифмический спад пиков (20 dB/с).

### 3. CoreAudio DSP на микрофонных входах:
- **3-полосный эквалайзер:** Low-Cut / High-Pass фильтр (80 Гц), полоса презенса вокала (2.8 кГц), полоса прозрачности (10 кГц).
- **Apple Studio Dynamics Processor:** аппаратный компрессор для плотного контроля динамики вокала.
- **Apple Studio Large Hall Reverb:** пространственный ревербератор с независимыми регуляторами Send на каждом микрофоне.
- **Низкая задержка CoreAudio:** нативная сквозная задержка от ~3.8 мс (буфер 64 фрейма) до ~11.8 мс (стандартный буфер 256 фреймов) при 48 кГц на Apple Silicon.

### 4. Управление и CoreMIDI:
- **Поддержка MIDI 1.0 и UMP (Universal MIDI Packet):** декодирование Control Change, Note On/Off, Program Change, Pitch Bend.
- **Безопасная сценическая семантика:** неназначенные ноты клавиатуры игнорируются и никогда не вызывают случайный запуск или остановку фонограммы.
- **Пороговая педаль сустейна (CC 64):** запуск Play/Pause срабатывает строго по нарастающему фронту ($\text{val} \ge 64$), исключая дребезг.
- **MIDI Learning:** интерактивное назначение любых контролов и кнопок с сохранением в `UserDefaults`.
- **Горячее подключение (Hot-Plug):** автоматическое переподключение контроллеров при включении/выключении USB кабелей во время саундчека.

## 🚀 Быстрый запуск

### Системные требования:
- **macOS:** 13.0 (Ventura) или новее;
- **Архитектура:** Apple Silicon (M1 / M2 / M3 / M4);
- **Инструменты сборки:** Swift 5.9+ / Xcode Command Line Tools.

### Запуск из исходного кода:
```bash
# Клонирование репозитория
git clone https://github.com/chumafox/StageFlow.git
cd StageFlow

# Запуск тестов (100% PASS, 92 теста)
swift test

# Запуск приложения в режиме разработки
swift run
```

### Сборка автономного приложения (StageFlow.app):
```bash
# Сборка релизного бандла с песочницей и разрешениями микрофона
./Scripts/package_app.sh

# Запуск готового приложения
open build/StageFlow.app
```

## 📁 Структура проекта

```
StageFlow/
├── Package.swift               # Спецификация SwiftPM (без сторонних зависимостей)
├── Info.plist                  # Метаданные бандла и описание доступа к микрофону
├── StageFlow.entitlements      # Права песочницы (App Sandbox, Audio Input, Bookmarks)
├── Scripts/
│   └── package_app.sh          # Автоматическая сборка StageFlow.app
├── Documentation/
│   ├── ADR/                    # Архитектурные решения (ADR-001 - ADR-005)
│   └── Validation/             # Протоколы валидации этапов (E00 - E14)
└── Sources/
    └── StageFlow/
        ├── App.swift           # Точка входа приложения (@main)
        ├── Models/
        │   ├── AppState.swift  # Реактивное состояние UI, сетлиста и суфлёра
        │   └── SongTrack.swift # Модели трека, строк и сегментов аккордов
        ├── Services/
        │   ├── AudioGraphController.swift # 4-канальный CoreAudio граф (FOH/IEM)
        │   ├── LiveAudioEngine.swift      # Координатор звука, DSP и прав микрофона
        │   ├── TransportController.swift  # Конечный автомат аудио-транспорта
        │   ├── MeteringService.swift      # vDSP lock-free измеритель уровней в dBFS
        │   ├── MIDIManager.swift          # CoreMIDI декодер UMP и legacy сообщений
        │   ├── MIDIMappingStore.swift     # Персистентное хранилище маппингов
        │   ├── TrackImporter.swift        # Неблокирующий асинхронный импорт треков
        │   ├── SetlistStore.swift         # Атомарное версионированное хранилище сетлиста
        │   └── PerformanceSignposts.swift # Инструменты профилирования OSSignposter
        └── Views/
            ├── StageFlowMainView.swift    # Главное сценическое окно (HSplitView)
            ├── StagePrompterView.swift    # Телесуфлер с аккордами и автоскроллом
            ├── PlaylistView.swift         # Сетлист, пакетный импорт и релинк файлов
            ├── MixerControls.swift        # Фейдеры громкости, кнопки Mute/Solo и DSP
            ├── VUMeterView.swift          # Светодиодные индикаторы уровня сигнала
            └── DiagnosticsView.swift      # Панель состояния движка и оборудования
```
