# StageFlow 🎛️
### Нативный гибрид Stage Traxx 3 и Apple MainStage для macOS (Apple Silicon M1+)

**StageFlow** — профессиональное сценическое рабочее место для живых выступлений, объединяющее плеер фонограмм и плейлистов с текстами/аккордами (функционал **Stage Traxx 3**) и живой DSP-микшер с независимой маршрутизацией FOH/In-Ear и обработкой микрофонов (функционал **Apple MainStage**).

---

## 🌟 Ключевые возможности

1. **Сценический плеер и тексты (Stage Traxx 3):**
   * Поддержка плейлистов / сет-листов с порядком песен.
   * Чтение встроенных тегов текстов (`USLT`, `lyrics` в MP3 / M4A / WAV) и внешних синхронизированных `.lrc` / `.txt`.
   * Распознавание синтаксиса **ChordPro** (`[Am]`, `[C]`, `[G#m7]`) и временных меток `[01:23.45]`.
   * **Stage Prompter (Телесуфлер):** крупный высококонтрастный шрифт, золотые аккорды над слогами, плавный автоматический скролл под воспроизведение, кнопки масштабирования размера шрифта.

2. **Двухшинный живой микшер (Apple MainStage):**
   * **FOH Bus (Main Speakers):** общий мастер-микс в зал.
   * **IEM Aux Bus (In-Ear Monitor):** независимый персональный ушной мониторинг для музыкантов.
   * У каждого канала (бэкинг-трек, Mic 1, Mic 2) есть **два независимых фейдера**: можно сделать вокал и подсказки громче в ушах, не трогая баланс в зале.
   * 14-сегментные светодиодные VU-индикаторы уровня в реальном времени.

3. **CoreAudio DSP на микрофонах:**
   * **3-полосный параметрический EQ:** Low-Cut / High-Pass фильтр (80 Гц), полоса презенса вокала (2.8 кГц), полоса прозрачности (10 кГц).
   * **Apple Studio Dynamics Processor:** аппаратный компрессор для плотного контроля вокала.
   * **Apple Studio Large Hall Reverb:** пространственный ревербератор с независимой регулировкой посыла (Send) на каждом микрофоне.
   * Задержка (latency) ~2.5 мс — нулевая ощутимая задержка в ушных мониторах.

4. **Сценический контроль:**
   * Горячие клавиши: `Space` — Play/Pause, быстрый сброс и перемотка.
   * **CoreMIDI поддержка:** подключение любых MIDI-контроллеров, клавиатур и педалей (AirTurn, Behringer и др.).

## 🚀 Быстрый запуск

### Вариант 1: Через терминал
```bash
cd /Users/alexnovak/.gemini/antigravity-cli/scratch/StageFlow
./run.sh
```

### Вариант 2: В Xcode
Просто дважды кликните файл `Package.swift` в папке проекта или выполните:
```bash
open /Users/alexnovak/.gemini/antigravity-cli/scratch/StageFlow/Package.swift
```
И нажмите `Cmd + R` для запуска.

## 📁 Структура проекта

```
StageFlow/
├── Package.swift               # Спецификация пакета Swift 5.9+ / macOS 13+
├── run.sh                      # Скрипт быстрого запуска
├── README.md                   # Документация
└── Sources/
    └── StageFlow/
        ├── App.swift           # Точка входа приложения (@main)
        ├── Models/
        │   ├── AppState.swift  # Реактивное состояние UI и плейлиста
        │   └── SongTrack.swift # Модели трека, строк и аккордов
        ├── Services/
        │   ├── LiveAudioEngine.swift # Двухшинный CoreAudio граф (FOH + IEM)
        │   ├── LyricsParser.swift    # Парсер ChordPro, USLT и таймкодов
        │   └── MIDIManager.swift     # CoreMIDI обработчик педалей и контроллеров
        └── Views/
            ├── StageFlowMainView.swift # Главное сценическое окно (HSplitView)
            ├── StagePrompterView.swift # Телесуфлер с аккордами и автоскроллом
            ├── PlaylistView.swift      # Сетлист и диалог добавления файлов
            ├── MixerControls.swift     # Фейдеры, карточки каналов и DSP
            └── VUMeterView.swift       # Сегментные светодиодные индикаторы
```
